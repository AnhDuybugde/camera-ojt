# Project Brief

## De bai

Camera theo doi luu luong nguoi trong phong, mat do, luong di chuyen dua tren camera gan tren tuong.

## Thanh phan chinh

- Camera input: doc frame tu camera IP, webcam hoac file video.
- Person detection: phat hien nguoi tren tung frame.
- Multi-object tracking: gan ID cho tung nguoi qua cac frame.
- Analytics: dem nguoi, tinh mat do theo vung, luu trajectory va huong di chuyen.
- Visualization: ve bounding box, ID, heatmap, zone count va export video/report.

## Gia dinh ky thuat ban dau

- Camera gan tren tuong, goc nhin nghieng hoac ngang.
- Can hieu chinh vung phong bang polygon zones trong file config.
